# Halloween-Project-2
2D top-down "horror" game where you collect candy while trying not to go insane!

This is a remake of a game I made in my high school Programming 1 class. The original game was made in Visual Basic during 2018.

This game is made using the Odin programming language and raylib game framework.

## Controls
* `\`` - Exit Game
* `Y/Space/Enter` - Exit When Prompted
* `N/Escape` - Don't Exit When Prompted
---
* `W` - Move Character Up
* `A` - Move Character Left
* `S` - Move Character Down
* `D` - Move Character Right
---
* `E` - Interact
* `I` - Toggle Inventory
* `M` - Toggle Map
